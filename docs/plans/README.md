# Планы крупной работы

Здесь лежат планы, которые пишутся **до** кода: новая сущность или домен, изменение схемы Mongo,
контракт наружу (API, MCP-тул, вебхук), конечный автомат, миграция данных, auth-флоу. Критерий
«крупной» — в `AGENTS.md` («Сначала оцени размер работы»).

Мелкая и средняя работа плана не требует. Документ ради документа хуже его отсутствия: он
протухает и потом врёт. Роадмапы (`docs/roadmaps/`) — про направление, план — про одну задачу.

## Имя файла

`<домен>-<что-делаем>.ru.md` строчными через дефис: `articles-translation-groups.ru.md`,
`auth-passkeys.ru.md`. Суффикс языка — как у всех документов, его требует `check-docs-structure`.
Без дат в имени — дата живёт внутри. Новый план добавляется строкой в список ниже: в общий
индекс `docs/README.md` планы не попадают, их карта — здесь.

## Что внутри

Шапка: **дата**, **состояние** (`черновик` / `согласован` / `в работе` / `закрыт`), одна фраза о
задаче. Состояние правится по ходу — устаревшее «не начато» на реализованном плане заставляет
делать работу заново.

Дальше — то, что делает риск понятным. Не всё сразу, а что применимо:

- конечный автомат → **матрица состояние × событие**, включая повторы и запрещённые переходы;
- изменение контракта API / MCP / DTO → **список потребителей**;
- изменение схемы Mongo → **backfill, откат, индексы**;
- новый роут → **кто имеет доступ** и какая обёртка это обеспечивает;
- всегда → **что вне задачи** и **критерий приёмки** (наблюдаемый признак, а не «работает»).

Если матрицу составить не получается — задача ещё не понята, и это сигнал вернуться к выяснению
требований, а не начинать код.

## Что при выкатке

Отдельный раздел в конце плана, если работа требует действий владельца руками: миграции,
индексы, новые секреты и Variables, порядок накатки, что необратимо. Агент не пушит и не
деплоит — этот раздел единственный канал, которым такие вещи доходят.

## Когда план закрыт

Состояние `закрыт` + ссылка на PR. Решения, которые захочется отменить, переносятся в
`docs/DECISIONS_RU.md` отдельной записью — план читают один раз, журнал — постоянно.
