# CLAUDE.md

Следуй `./AGENTS.md`, импортированному ниже:

@AGENTS.md

Этот файл — **только адаптер Claude Code**. Не дублируй здесь правила проекта: они живут в
`AGENTS.md`, который читают все инструменты (Claude, Codex, Cursor). Ниже — исключительно про
рантайм Claude.

- **Коммит только после проверки диффа владельцем.** Порядок: этап закончен и прогнан →
  перечислить, что менялось → владелец смотрит у себя в IDE → «ок, коммить» → тогда `git add` и
  коммит. Один «ок» относится к одному коммиту.
- **Ветку пушь и PR открывай сам** — всегда `git push origin <ветка>` с явным именем ветки,
  PR в `develop` через `gh pr create` с описанием по шаблону, ссылку отдавай в ответе. **В `main`
  — никогда:** `prod-deploy.yml` триггерится на push в `main`, это выкатка в прод; туда только PR
  `develop → main`, мержит владелец (`gh pr merge` тоже под запретом).
- **Гейт `scripts/guard-external.sh`** (`.claude/settings.json`, `PreToolUse` для Bash) читает
  строку команды регэкспами по словам: голый `git push` / в `main` / с force / `--all`,
  `gh pr merge`, `gh api` с записью, `docker volume rm|prune`, `compose down -v`, `crontab -r`,
  удаление бэкапов, `pnpm <x>:prod`, имя файла `.env.prod`, запуск restore. Кавычки
  раскрываются: `ssh host 'git push origin main'` и `bash -c "…"` тоже ловятся; heredoc с такой
  командой в тексте — тоже. Такой файл пиши через инструмент Write, а не через shell — это не
  обход, а штатный путь. Таблица вердиктов — `scripts/guard-external.test.mjs`.
- **Fail-closed только внутри скрипта.** Отсутствующий или неисполняемый хук Claude Code не
  блокирует (126/127 = «не мешать»), поэтому хук в `settings.json` — обёртка с `[ -x ]`, а
  `check-agent-gate` в `pnpm gates` следит за битом и обёрткой.
- **Сообщение коммита — про причину**, а не про перечень файлов: что было сломано, почему выбрано
  это решение и что сломается, если вернуть как было.
- **`pnpm test` гоняй сам** перед показом диффа: `pre-push` на твоём пути не сработает, а
  `pre-commit` тесты не запускает.
- **Субагенты и воркфлоу — для разведки и адверсарных проверок**, не для параллельных правок
  одного репозитория: читают многие, пишет один.
- `.claude/settings.local.json` и `.claude/agent-memory/` — локальный рантайм, не коммитятся.
